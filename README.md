# 我的美食口袋名單

以溫暖手帳風整理「想吃／吃過」的店家。使用原生 HTML、CSS、JavaScript，沒有框架、後端或外部 API。

## 功能

- 六家政大周邊店家及獨立詳細網址。
- 正餐／早午餐／甜點／飲料多分類，搭配想吃／吃過篩選。
- 網頁新增、編輯、確認刪除及切換狀態。
- 餐點、價格與推薦商品。
- 自製 SVG 分類插畫，也可上傳照片。
- 多張菜單、放大查看及官方菜單連結。
- IndexedDB 本機保存、JSON 匯出與匯入，備份包含圖片。
- 手機與電腦響應式排版。

六家店的預算、地址及推薦商品由使用者提供。沒有提供的單品價格不補寫，所有初始菜單顯示「菜單待補充」。

## 儲存與備份

在網站新增或修改的資料只會保存在目前的瀏覽器，不會自動同步至其他裝置或更新公開網站。使用者可以透過「備份管理」匯出及匯入資料，備份內容包含店家資料、照片與菜單。

## 後續擴充方式

本專案透過 AGENTS.md 統一店家資料格式、網頁風格與修改規則。之後新增店家時，AI 可以依照這些規則整理資料，沿用既有版型呈現內容，讓新加入的店家維持一致的格式。若資料不完整，AI 會先詢問，不自行補寫；查詢菜單時，則須確認官方來源與適用分店。

## 檔案

- `AGENTS.md`：記錄專案規則，讓 AI 依照一致的方式修改與新增內容。
- `index.html`：美食口袋名單首頁。
- `restaurant.html`：店家詳細介紹頁。
- `assets/`：存放網頁樣式、互動功能與圖示。
- `data/restaurants.json`：存放店家資料。
